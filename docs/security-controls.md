# Security controls matrix

Each control names where it is implemented and which automated check proves it. "CI" entries run in GitHub Actions; everything under `tests/` runs against real PostgreSQL, Redis and an S3 server.

## OWASP Top 10 (2021) mapping

| Risk | Control | Implementation | Verification |
|---|---|---|---|
| A01 Broken access control | Org-scoped queries; role ceiling x relationship; 404 for foreign ids; RLS; composite FKs | `app/authz.py`, `app/models.py`, `migrations/versions/0001_initial_schema.py` | `test_tenant_isolation.py`, `test_rbac.py` |
| A02 Cryptographic failures | Argon2id passwords; TLS 1.3 policy at the ALB; `rds.force_ssl`; SSE-KMS on S3 with a rotating CMK; secrets in Secrets Manager; no secrets in the repo | `app/security.py`, `infra/modules/*` | `test_passwords_are_stored_as_argon2id`, Checkov, gitleaks |
| A03 Injection | ORM and bound parameters only; strict Pydantic models; no shell or template execution on user input | `app/routers/*`, `app/schemas.py` | search injection test, Semgrep, Bandit, CodeQL |
| A04 Insecure design | Threat model; tenant isolation in four layers; fail-closed rate limiter; append-only audit | `docs/threat-model.md` | `test_rate_limiter_fails_closed_when_redis_is_down` |
| A05 Security misconfiguration | Security headers on every response (also errors); docs/OpenAPI off outside local; strict config validation (weak secret, wildcard CORS, wildcard hosts refused); non-root read-only container; no SSH | `app/middleware.py`, `app/config.py`, `Dockerfile`, compose | `test_security_headers_*`, `test_production_config_is_validated`, `test_docs_disabled_when_configured` |
| A06 Vulnerable components | Pinned requirements, Dependabot, pip-audit, Trivy (fs and image), ECR scan on push | `requirements*.txt`, `.github/` | CI `security.yml`, `ci.yml` |
| A07 Identification and authentication failures | Password policy (length, common list, no email), IP and per-account throttling, generic failures, refresh rotation with replay detection, logout revokes the family, immediate effect of deactivation | `app/routers/auth.py`, `app/redis_stores.py`, `app/deps.py` | `test_auth.py` |
| A08 Software and data integrity failures | SHA-256 stored per version and returned with each download; immutable ECR tags; CI gates before image push | `app/uploads.py`, `infra/modules/compute` | roundtrip test compares hashes |
| A09 Logging and monitoring failures | Audit trail for authentication, access, sharing and denials; JSON logs with request and trace ids; Prometheus alerts for replay, denial spikes, login failures | `app/audit.py`, `deploy/prometheus/alerts.yml` | `test_login_is_audited`, `test_download_is_audited`, denial audit assertions |
| A10 SSRF | The service never fetches user-supplied URLs; IMDSv2 required with hop limit 1; egress limited to 443 and the VPC | `infra/modules/compute` | design; Checkov |

## Required controls from the brief

| Requirement | Control | Where | Test |
|---|---|---|---|
| Input validation | Pydantic schemas with `extra="forbid"`, length and pattern limits, bounded pagination, UUID path types | `app/schemas.py`, routers | `test_unknown_fields_are_rejected`, pagination test |
| Upload hardening | 50 MB streamed cap, type allowlist, magic-byte match, sanitized names, random keys | `app/uploads.py` | `test_upload_validation`, size and filename tests |
| Rate limiting | Redis fixed window: 5/min login per IP, 100/min per user, 30/min public share endpoint | `app/redis_stores.py`, `app/deps.py` | `test_login_rate_limited_per_ip`, `test_public_endpoint_is_rate_limited` |
| Security headers | CSP `default-src 'none'`, nosniff, DENY framing, no-referrer, COOP/CORP, HSTS in staging/production, `no-store` | `app/middleware.py` | `test_security_headers_and_request_id` |
| Secrets management | Environment only; Secrets Manager in AWS (RDS master secret is service-managed and never enters Terraform state); random local secrets generated by `make secrets`; `.env` ignored | `app/config.py`, `infra/`, `scripts/gen_env.sh` | gitleaks, Trivy secret scan |
| Least privilege | Unprivileged DB role without ownership or `BYPASSRLS`; no UPDATE/DELETE on audit; instance role limited to one bucket, one KMS key, three secrets, one ECR repo; security groups chained; container drops all capabilities | migration grants, `infra/modules/compute` | `test_runtime_role_is_not_privileged`, `test_bootstrap_role_*`, Checkov |
| Tenant isolation tests | See `test_tenant_isolation.py` | | 13 scenarios |
| Dependency scanning | pip-audit (strict), Dependabot, Trivy | `.github/workflows/security.yml` | CI |
| Container scanning | Trivy image scan fails on fixable HIGH/CRITICAL; non-root assertion | `.github/workflows/ci.yml` | CI |
| Short-lived signed URLs | 60 s default, 300 s hard cap, attachment disposition | `app/storage.py`, `app/config.py` | `test_presigned_url_*` (the expiry test runs against real MinIO) |
| Access expiration | Per-user grants and share links expire; evaluated on every request, by the database clock for links | `app/authz.py`, `app/routers/shared.py` | `test_expired_permission_denies_access`, `test_expired_link_is_refused_and_audited` |
| Concurrency safety | Row lock for version numbers; atomic conditional UPDATE for download caps; GETDEL for refresh rotation; upsert for grants | routers, `app/redis_stores.py` | `test_concurrent_*`, `test_max_downloads_holds_under_concurrency`, `test_parallel_tenants_do_not_bleed_context` |

## Static analysis results recorded during development

| Tool | Scope | Result |
|---|---|---|
| ruff, mypy `--strict` | `app/` and tests | clean |
| Bandit (medium and above) | `app/`, `scripts/` | no findings |
| Semgrep (python, owasp-top-ten, jwt rule packs) | `app/` | 0 findings |
| pip-audit | `requirements.txt` | no known vulnerabilities |
| Checkov | `infra/` | 258 passed, 0 failed, 17 skipped; every skip is annotated at the resource with a reason |
| `terraform validate` | `infra/environments/dev` | valid (no plan or apply was run: no AWS credentials were used) |

Trivy, gitleaks, CodeQL and tflint are wired into CI but were not run locally, because the tools or the registries behind them were not available in the development sandbox.
